| ID | Severity | Finding | Status | Evidence |
|---|---|---|---|---|
| A1 | High | After a short write (e.g. ENOSPC), `FileStorage` kept accepting appends after the partial record. ## Resume claims checked

| Claim | Supported? |
|---|---|
| "5-node cluster" | Yes, now: 5-process chaos runs and failover runs. Before this audit only in-process tests used 5 nodes. |
| "gRPC-based inter-node communication" | **No.** Peers use gob-encoded HTTP/1.1 POSTs (`raft/http_transport.go`); clients use JSON/REST. Say "HTTP RPC". |
| "recovers within 2x election timeout" | Yes on this machine: 45/45 trials under 2x the max timeout (1,200 ms), 44/45 under 2x the min timeout (600 ms). Single machine, localhost network. |
| "Go, gRPC, C++" | Go yes. gRPC no. C++ no: there is no C++ code; the optional store is Rust behind a C header (`kv/lsmstore/lsm.h`), and it cannot currently be built from public sources. |
